## Title
Campus2Career: An AI Exam-Prep Tutor Powered by Strands Decider 2B

## Description (max 512 chars)
Campus2Career is an AI tutor for college students that uses Strands Decider 2B to pick the right study tool for every request -- concept explanation, exam planning, practice questions, code debugging, resource recommendations, or aptitude coaching -- before Amazon Bedrock answers. One forward pass selects the tool; low-confidence requests ask the student to clarify.
